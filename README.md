# PDF Header / Footer Editor

Веб-инструмент для добавления header, footer и финальной страницы с реквизитами в PDF-файлы. Вся обработка происходит локально в браузере — файлы никуда не отправляются.

## Возможности

- Header и footer с текстом, выравниванием, шрифтом, цветом и кликабельной ссылкой (с поддержкой UTM-меток)
- Фон/рамка вокруг текста header и footer (со скруглением углов)
- Дополнительная последняя страница с логотипом, текстом и ссылкой
- Пакетная обработка нескольких PDF за раз (результат — ZIP-архив, если файлов больше одного)

## Стек

React + TypeScript + Vite, [pdf-lib](https://pdf-lib.js.org/) для работы с PDF, Tailwind CSS + shadcn/ui (на базе [Base UI](https://base-ui.com/)) для интерфейса, Zustand для состояния.

## Запуск

```bash
pnpm install
pnpm dev
```

Сборка продакшн-версии:

```bash
pnpm build
```
